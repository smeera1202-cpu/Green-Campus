# 🌱 Smart Campus Gardening System

A web-based system designed to help educational institutions manage and monitor campus gardening activities efficiently.

## 📌 About the Project

The **Smart Campus Gardening System** provides a centralized platform for managing campus gardens, plants, watering schedules, maintenance activities, and garden-related information.

The goal is to make campus gardening more **organized, efficient, and sustainable** by replacing manual tracking with a simple digital system.

## ✨ Features

* 🌿 Plant and garden management
* 💧 Watering schedule management
* 📅 Gardening and maintenance scheduling
* 🗄️ Database-based data management
* 📊 Garden monitoring
* ⚙️ Automated scheduling support
* 🖥️ User-friendly web interface
* 📱 Responsive design

## 🛠️ Technologies Used

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/smart-campus-gardening.git
cd smart-campus-gardening
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the application

```bash
python app.py
```

### 4. Open the application

Open your browser and visit:

```text
http://localhost:5000
```
